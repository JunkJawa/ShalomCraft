# ShalomCraft

Jewish food, holiday items and decor for the CatTech 2 modpack (Minecraft 1.21.1, NeoForge 21.1.213).
Requires Farmer's Delight. Install the jar on the server and on every client.

Build: push to GitHub, open the Actions tab, run "Build ShalomCraft", download the `shalomcraft-jar` artifact.
Assets (textures, models, lang, recipes) are generated by `python3 tools/gen_assets.py`.
